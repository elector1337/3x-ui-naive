**3X-UI** — advanced, open-source web-based control panel designed for managing Xray-core server. It offers a user-friendly interface for configuring and monitoring various VPN and proxy protocols.

> [!IMPORTANT]
> This project is only for personal usage, please do not use it for illegal purposes, and please do not use it in a production environment.

As an enhanced fork of the original X-UI project, 3X-UI provides improved stability, broader protocol support, and additional features.

---

## NaiveProxy support (this fork)

This fork adds first-class support for [NaiveProxy](https://github.com/klzgrad/naiveproxy)
servers managed alongside Xray. NaiveProxy is **not** an Xray protocol — it's
Caddy with the `forward_proxy` plugin from klzgrad — so the panel runs it as a
separate child process, with its own config, log and ACME storage.

**What you get:**

- dedicated UI page `/panel/naive` with list, form, status badges and a mobile card view
- one-click **Install Caddy** button — the panel builds a Caddy binary with `forward_proxy` plugin via `xcaddy`
- two TLS modes: **Auto TLS (Let's Encrypt)** or your own cert/key files
- **Advanced (raw Caddyfile) editor** with live `caddy adapt` validation
- three-level health check: `running` (process) → `listening` (TCP) → `responding` (HTTPS)
- cross-port collision checks against Xray inbounds — no more port stomp
- REST API under `/panel/api/naive` (CRUD + start/stop/restart + preview + validate + reset-traffic)
- isolated `XDG_DATA_HOME` per server so multiple naives don't share state
- auto-restart of `enable=true` servers on panel boot
- **per-server traffic stats** counted in the kernel (nftables), with a usage column and reset button — Linux + root
- **traffic limits, expiry & auto-stop**, plus periodic counter resets (daily / weekly / monthly)
- **multiple users per server** — extra `basic_auth` credentials, each with its own client URL and QR
- **QR code / share-link** generator for every credential
- **HTTP/3 (QUIC) toggle** per server
- **subscription integration** — tag a server with a `subId` and its client URLs join that subscription
- **Telegram bot report** — naive servers in the admin usage report
- `authPass` and extra-user passwords **encrypted at rest** (AES-256-GCM)

**Client URL** generated by the panel:

```
naive+https://USER:PASS@DOMAIN:PORT
```

**Full setup, API reference and configuration details:** see [`docs/NAIVE.md`](./docs/NAIVE.md).
**What's different from upstream 3x-ui:** see [`CHANGELOG.md`](./CHANGELOG.md).

## Quick Start

Install this fork (with NaiveProxy support):

```bash
bash <(curl -Ls https://raw.githubusercontent.com/elector1337/3x-ui-naive/feature/naive-proxy/install.sh)
```

To build Caddy with `forward_proxy` automatically during install (skips the
interactive prompt), set `NAIVE_INSTALL_CADDY=yes`:

```bash
NAIVE_INSTALL_CADDY=yes bash <(curl -Ls https://raw.githubusercontent.com/elector1337/3x-ui-naive/feature/naive-proxy/install.sh)
```

For full documentation of the upstream panel, please visit the
[3x-ui project Wiki](https://github.com/MHSanaei/3x-ui/wiki). For the
fork-specific bits, see [`docs/NAIVE.md`](./docs/NAIVE.md) and
[`CHANGELOG.md`](./CHANGELOG.md).
